# 🔐 Part 2 · Cybersecurity & Ethical Hacking

> ⚠️ Only practise on your own machines, intentionally vulnerable labs, CTFs and bug bounty targets that are in scope. Scanning or attacking systems without written permission is illegal (in India under the IT Act, 2000).

## Stage 1 · Foundations  
*Dec 2026 – Jun 2027 (alongside DSA)*

**Goal:** You can't hack what you don't understand. Networking + Linux + scripting first.

- [ ] Networking: OSI & TCP/IP, IP addressing & subnetting, DNS, HTTP/HTTPS, TLS
- [ ] Linux command line, permissions, processes, services, logs
- [ ] Bash and Python scripting for automation
- [ ] Windows basics & Active Directory concepts
- [ ] How the web works: cookies, sessions, APIs

**Where to learn:** [Professor Messer (Network+ / Security+)](https://www.professormesser.com) · [Cisco Networking Academy](https://www.netacad.com) · [Linux Journey](https://linuxjourney.com) · [OverTheWire – Bandit](https://overthewire.org/wargames/bandit/)

## Stage 2 · Web Application Security  
*Jul – Dec 2027*

**Goal:** Most bugs live in web apps. Learn the OWASP Top 10 by breaking practice labs.

- [ ] OWASP Top 10: injection, broken access control, XSS, SSRF, auth flaws
- [ ] SQL injection, command injection, file upload bugs
- [ ] IDOR & business-logic flaws
- [ ] JWT, OAuth and session security
- [ ] Secure coding & how to fix each bug

**Where to learn:** [PortSwigger Web Security Academy (free)](https://portswigger.net/web-security) · [OWASP Top 10](https://owasp.org/www-project-top-ten/) · [OWASP Juice Shop (practice app)](https://owasp.org/www-project-juice-shop/)

## Stage 3 · Practice Platforms & CTFs  
*2027 onwards (weekly)*

**Goal:** Hands-on practice on legal, intentionally vulnerable labs.

- [ ] Finish beginner paths, then move to medium boxes
- [ ] Write a public write-up for every box / CTF you solve
- [ ] Play at least one CTF a month with a team

**Where to learn:** [TryHackMe](https://tryhackme.com) · [Hack The Box](https://www.hackthebox.com) · [HTB Academy](https://academy.hackthebox.com) · [picoCTF](https://picoctf.org) · [CTFtime (CTF calendar)](https://ctftime.org) · [Root Me](https://www.root-me.org) · [VulnHub](https://www.vulnhub.com) · [LetsDefend (blue team)](https://letsdefend.io) · [CyberDefenders (blue team)](https://cyberdefenders.org) · [Blue Team Labs Online](https://blueteamlabs.online)

## Stage 4 · Certifications  
*2027 – 2029*

**Goal:** Proof of skill for recruiters. Go in this order.

- [ ] ISC2 Certified in Cybersecurity (CC) – free entry level (2027)
- [ ] CompTIA Security+ (2027–28)
- [ ] eJPT – junior penetration tester (2028)
- [ ] HTB CPTS or TCM PNPT – practical pentest (2028–29)
- [ ] OSCP – the industry gold standard (2029)

**Where to learn:** [ISC2 CC](https://www.isc2.org/certifications/cc) · [CompTIA Security+](https://www.comptia.org/certifications/security) · [INE (eJPT)](https://ine.com) · [OffSec OSCP (PEN-200)](https://www.offsec.com/courses/pen-200/)

## Stage 5 · Bug Bounty (legal hacking for money)  
*2028 onwards*

**Goal:** Only test targets that are in a program's scope. Read every rule first.

- [ ] Read disclosed reports to learn how real bugs are found
- [ ] Recon → map the app → hunt one bug class deeply
- [ ] Write clear reports with impact and steps to reproduce

**Where to learn:** [HackerOne](https://www.hackerone.com) · [Bugcrowd](https://www.bugcrowd.com) · [Intigriti](https://www.intigriti.com) · [YesWeHack](https://www.yeswehack.com)

## Stage 6 · Specialise  
*2029 – 2030*

**Goal:** Pick one direction and go deep. All of these are growing till 2030 and beyond.

- [ ] Penetration testing / red team
- [ ] Application security & DevSecOps
- [ ] Cloud security (AWS, Azure, GCP)
- [ ] SOC analyst / incident response / digital forensics
- [ ] AI & LLM security (prompt injection, model abuse)
- [ ] Malware analysis & reverse engineering

**Where to learn:** [MITRE ATT&CK](https://attack.mitre.org) · [flAWS (AWS security game)](http://flaws.cloud) · [OWASP GenAI / LLM Top 10](https://genai.owasp.org)
